Sales Performance Analysis
Project Overview

This project analyzes sales performance data for 2024 and 2025 using Microsoft Excel, Power Query, and Power BI.

The goal of the analysis was to transform raw sales data into meaningful business insights and an interactive dashboard that helps understand revenue, product performance, sales representatives, customer ratings, payment methods, and yearly performance.

Tools Used
Microsoft Excel
Power Query
Power BI
Data Visualization
Key Analysis

The project examines:

Total sales revenue
Sales quantity
Average transaction value
Year-over-year revenue performance
Product performance
Sales representative performance
Customer ratings
Payment methods
Monthly sales trends
Key Findings
Total revenue was approximately ₦340.4 million.
Revenue increased significantly from 2024 to 2025.
Phones generated the highest product revenue.
Sales performance varied across representatives.
Customer ratings were analyzed across products and payment methods.
Dashboard

An interactive Power BI dashboard was created to provide a visual overview of sales performance and allow users to explore the data using filters and key performance indicators.

Objective

The objective of this project was to demonstrate practical skills in data cleaning, analysis, visualization, dashboard development, and business reporting.
